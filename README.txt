STORYVERSE - STORYBOOK-LIKE WATTPAD PROJECT
============================================

FILES
- index.html: homepage with 30 story cards, search, genres and navigation
- story.html: reusable reading page; each card opens its own story using ?id=
- style.css: one external stylesheet for all pages
- stories.js: story information for all 30 stories
- script.js: interactive features
- images/: 30 local cover SVGs and 30 local chapter illustrations

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a browser, or use Visual Studio Code with the Live Server extension.
3. Click a book's Read story button to open its chapter.
4. Use the theme button, like buttons, genre filters, search, sort, synopsis toggle, and reading progress bar.

PROJECT FEATURES
- 30 different story covers and 30 supporting illustrations stored in images/
- Each story has one chapter, title, author, genre, synopsis, and story content
- Responsive layout for desktop, tablet and mobile
- Semantic HTML elements: header, nav, main, section, article, footer
- External CSS and JavaScript files
- Dark/light mode, favorites, search, genre filtering, sorting, book details dialog,
  show/hide synopsis, start-reading button, and reading progress indicator
- Every Read story button links to the corresponding story page

NOTE
The short story text is sample content created for this school project. You can personalize
the names, story text, colors, and design before submitting.
